# 说明
1. 文档中加入一些 frontmatter
2. 具体有：
```
title: 文章标题
description: 一句话描述
createdAt: 2025-05-21
updatedAt: 2025-05-21
categories:
  - 示例分类
author: 你的昵称
image: "@assets/demo.png"
tags:
  - 示例标签
draft: false
hideToc: false
repo: my-repo-id
path: docs/my-file. md
branch: feature-branch
commit: "Update documentation for new feature"
```
3. 然后右键点击发布到 github 即可
